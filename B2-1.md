## 1. 처음 발견한 문제

초기 시안은 화면 구성이 부족한 것이 아니라, 생성형 AI가 화면마다 변하면 안 되는 요소까지 다시 그린 것이 가장 큰 문제였다.

| 문제 | 초기 상태 | 영향 |
|---|---|---|
| 공통 브랜드 불일치 | 페이지마다 로고 심볼과 Header 구성이 달랐다. | 하나의 서비스가 아니라 서로 다른 사이트처럼 보였다. |
| Footer 정보 불일치 | 대표이사·주소·신고번호·고객센터 정보가 화면마다 바뀌었다. | 검증되지 않은 정보가 생성되고 신뢰도가 낮아졌다. |
| 한글 생성 오류 | `파트너`가 다른 글자로 보이고 `간사이` 표기도 화면마다 달랐다. | 핵심 상품과 서비스 문구를 정확히 읽기 어려웠다. |
| 상품 데이터 불일치 | 동일 상품의 지역·기간·평점·가격이 화면마다 달라질 가능성이 있었다. | 메인→목록→상세의 정보 연속성이 깨졌다. |
| 관광 이미지 가짜 문자 | 야간 거리와 상점 간판에 실제로 읽을 수 없는 문자가 생겼다. | 실제 관광 사진처럼 보이지 않고 AI 생성 흔적이 강해졌다. |
| 랜드마크 구조 왜곡 | 오사카성·교토 거리·탑·금각사의 지붕선·난간·반사가 불규칙했다. | 카드에서는 작게 보이지만 상세 Hero에서 부자연스러움이 커졌다. |
| 화면 간 이미지 불일치 | 같은 핵심 상품이 화면마다 다른 사진으로 표현됐다. | 사용자가 같은 상품인지 즉시 연결하기 어려웠다. |

원인은 전체 UI를 화면별로 반복 생성하면서 로고·글자·상품 데이터·공통 UI·관광 사진을 모두 AI 출력에 맡긴 것이었다. 해결 방향은 V3 화면을 베이스로 고정하고, 관광 사진만 별도 생성·검수한 뒤 로고·한글·상품 정보·Header·Footer는 고정 자산으로 통제하는 것이었다.

### 4.3 수정 원칙

1. 로고와 글자는 이미지 생성 AI로 다시 그리지 않는다.
2. 공통 Header와 Footer는 동일한 고정 에셋을 사용한다.
3. 관광 사진만 별도 생성하고 검수를 통과한 자산만 화면에 넣는다.
4. 모든 생성 프롬프트와 결과 이미지를 보존한다.
5. 실제 장소 구조가 부정확하거나 가짜 문자가 보이면 폐기 또는 재생성한다.
6. V1·V2·V3 원본은 수정하지 않고 후가공 최종본을 별도 보존한다.

- 프롬프트 원문 파일명: `00_공통스타일_V1.txt`

```text
Create a high-fidelity desktop website UI for "JAPAN MATE", a Japanese package travel guide service targeting Korean users in their 20s and 30s who are visiting Japan for the first time. The interface language should be Korean. Use a clean, modern travel platform style with a professional and trustworthy look, and keep the visual identity polished and consistent.

Design style:
- modern travel booking platform
- clean and minimal layout
- elegant and premium but approachable
- realistic travel photos with sharp, advertisement-style quality
- desktop website UI, 16:9 aspect ratio
- high fidelity, polished Figma-style UI
- consistent spacing, grid layout, rounded cards, subtle shadows
- clear information hierarchy
- realistic and usable web components
- easy-to-read Korean typography
- polished, professional UX/UI design

Color and mood:
- main color: Japanese traditional red
- base colors: white and soft warm light gray
- text color: charcoal / dark gray
- accent colors: muted pink or soft beige only when needed
- overall mood: clean, trustworthy, travel-inspired, modern Japanese feeling

Branding:
- brand name: JAPAN MATE
- include a clean logo area in the header
- include consistent top navigation and footer
- the whole screen should feel like a professional Japanese package travel platform for Korean users

UI rules:
- use consistent header, navigation, buttons, cards, form styles, icons, and footer
- use Korean text labels that are readable and natural
- avoid distorted or broken text
- avoid cluttered composition
- prioritize a realistic website layout over artistic abstraction

Photo direction:
- use realistic Japan travel photos
- include iconic imagery such as Mt. Fuji, cherry blossoms, Kyoto streets, shrines, Tokyo skyline, Osaka landmarks, and scenic destinations
- images should look like real commercial travel website photos

- one screen of a desktop web UI
- 16:9 wide layout
- crisp, neat, visually consistent, submission-ready
```
